# Attribution — `graycart-n64`

Full policy and examples live in [`docs/ATTRIBUTION.md`](./docs/ATTRIBUTION.md), and third-party license boundaries live in [`THIRD_PARTY.md`](./THIRD_PARTY.md).

## Mandatory file-top rule

Every in-repo Rust (`.rs`) or Markdown (`.md`) file that cites, adapts, or cross-checks external documentation or code MUST include a header at the top of the file stating:

- **What** document, project, or section was used
- **Where** (URL and/or canonical name)
- **How** (*cited* / *inspired by* / *ported from* / *cross-checked against*)

Provenance archives under [`docs/provenance/`](./docs/provenance/README.md) do not replace per-file headers. Any file derived from ISC (`ares`) or BSD-3 (`cen64`, excluding its Angrylion-derived RDP) MUST preserve the upstream license notice in its header. GPL, MAME/Angrylion, and unlicensed code MUST NEVER be ported or pasted.
